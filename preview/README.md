# MyOpenProctor interactive preview

Open `index.html` to explore the proposed instructor and student interfaces.

## Instructor preview features
- Dashboard navigation
- Multiple exam cards
- Create Exam dialog
- Exam code generation
- Duration / assessment URL fields
- Excel and proctoring options
- Document upload control
- Student Preview button on every exam
- Session-review table
- Recording placeholder and objective event timeline

## Student preview features
- Clear step navigation
- System-check status
- Allowed resources and instructor document display
- Recording disclosure area
- Start preview session
- Running session timer
- Explicit End Session control
- Easy return to Instructor view

This folder is a UI/interaction preview. The production branch architecture also contains the desktop client foundation and database schema. Persistent cross-device exams, real uploads/recordings, authentication, and LTI require the backend deployment described in `../ARCHITECTURE.md`.
